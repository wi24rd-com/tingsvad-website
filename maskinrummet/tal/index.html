Tallene

Hvad kanten så. Talt hver time, ikke opfundet.

Fire tavler fra samme maskineri: en Cron Trigger i tingets Worker henter tal fra Cloudflares API’er hver time, gemmer dem i D1 og Workers KV, og siden her henter dem gennem Workers Cache. Ingen IP-adresser bliver hentet eller vist. Vælg en tavle – adressen følger med, så du kan dele den.

Hver dag banker robotter på tingsvad.dk med kendte angreb mod software, sitet slet ikke kører. Cloudflares værn stopper dem i det datacenter, der ligger nærmest angriberen, før de når tingets Workers. Her er, hvad værnet har set de seneste 30 døgn: hvor angrebene kom fra, hvilke regler der slog til, og hvad de ledte efter. Ingen IP-adresser bliver hentet eller vist.

Sådan tælles der

  1. Cron Trigger
  2. GraphQL Analytics API
  3. D1
  4. Workers KV
  5. Workers Cache
  6. Din browser

Kilden

Cloudflares GraphQL Analytics API for zonen tingsvad.dk: firewall-hændelser, alle forespørgsler og verificerede bots. Tokenet må kun læse analyse for denne ene zone.

Hver time

En Cron Trigger i tingets Worker spørger om dagens og gårsdagens døgn, ét døgn ad gangen, så Cloudflare ikke skal sample over en lang periode. Rækkerne gemmes i D1 i 95 dage.

Oversigten

Efter hver indsamling bygger Workeren de to oversigter og lægger dem i Workers KV. Siden henter dem gennem Workers Cache, som tømmes med et cache-tag, når der er nye tal.

Det, der ikke gemmes

IP-adresser bliver hverken hentet eller gemt. Stier vises uden forespørgselsdel, lange tokens skjules, og e-mailadresser i brugeragenter fjernes. Tal over lange perioder kan være samplet af Cloudflare og er derfor omtrentlige.

Lighthouse måler siderne i et laboratorium. Her er de målt hos rigtige gæster: hvor længe der gik, før det største indhold stod på skærmen, hvor hurtigt siden svarede på et klik, og om den hoppede rundt undervejs. Cloudflare Web Analytics måler det med et lille script uden cookies og uden at kende gæsten, og tinget henter tallene hver time.

Kilden

Cloudflare Web Analytics (Real User Monitoring) for tingsvad.dk, hentet fra GraphQL Analytics API på kontoniveau. Tokenet må kun læse analyse.

Hver time

En Cron Trigger i tingets Worker henter de seneste 7 døgn: sidevisninger, Core Web Vitals, indlæsningstider og hvor tiden går. Hver del hentes for sig, så én fejl ikke tager resten med.

Grænserne

God, kan forbedres og dårlig følger Googles grænser: LCP 2,5 og 4 sekunder, INP 200 og 500 millisekunder, CLS 0,1 og 0,25. Tallene er 75 %-fraktilen, som Google bruger.

Det, der ikke måles

Gæster, der blokerer scriptet eller ikke har JavaScript, tælles ikke. Der gemmes hverken IP-adresser, cookies eller fingeraftryk.

Værnet og Crawlerne viser, hvad der sker ved ét lille vadested. Cloudflare ser trafik fra hele Danmark og deler det åbent i Radar. Her står landets tal ved siden af tingets: hvor mange af forespørgslerne der kommer fra bots, hvilke AI-crawlere der er mest aktive, hvor angrebene kommer fra, hvor mange forbindelser der allerede er kvantesikre, og hvor hurtigt danskernes internet er.

Sådan tælles der

  1. Cron Trigger
  2. Radar API
  3. Workers KV
  4. Workers Cache
  5. Din browser

Kilden

Cloudflare Radar for Danmark (location=DK), hentet med Radar API. Radar bygger på trafikken gennem Cloudflares net og er andele, ikke antal. Data er CC BY-NC 4.0.

Hver time

En Cron Trigger i tingets Worker henter seksten Radar-oversigter og lægger dem samlet i Workers KV. Hver del hentes for sig, så én fejl ikke tager resten med.

Tingets egne tal

Sammenligningerne med tingsvad.dk kommer fra Værnet og Crawlerne: de verificerede bots, der kom forbi, og de lande, angrebene på tinget kom fra.

Det, der ikke gemmes

Radar er samlede tal for hele landet. Der hentes ingen data om enkelte personer, IP-adresser eller sites.
