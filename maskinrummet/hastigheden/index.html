Hastigheden

Hvor hurtigt tinget svarer, målt hos gæsterne selv.

Lighthouse måler siderne i et laboratorium. Her er de målt hos rigtige gæster: hvor længe der gik, før det største indhold stod på skærmen, hvor hurtigt siden svarede på et klik, og om den hoppede rundt undervejs. Cloudflare Web Analytics måler det med et lille script uden cookies og uden at kende gæsten, og tinget henter tallene hver time.

Sådan tælles der

  1. Web Analytics-beaconen
  2. GraphQL Analytics API
  3. Cron Trigger
  4. Workers KV
  5. Workers Cache
  6. Din browser

Kilden

Cloudflare Web Analytics (Real User Monitoring) for tingsvad.dk, hentet fra GraphQL Analytics API på kontoniveau. Tokenet må kun læse analyse.

Hver time

En Cron Trigger i tingets Worker henter de seneste 7 døgn: sidevisninger, Core Web Vitals, indlæsningstider og hvor tiden går. Hver del hentes for sig, så én fejl ikke tager resten med.

Grænserne

God, kan forbedres og dårlig følger Googles grænser: LCP 2,5 og 4 sekunder, INP 200 og 500 millisekunder, CLS 0,1 og 0,25. Tallene er 75 %-fraktilen, som Google bruger.

Det, der ikke måles

Gæster, der blokerer scriptet eller ikke har JavaScript, tælles ikke. Der gemmes hverken IP-adresser, cookies eller fingeraftryk.

Rå tal som JSON: /api/ting-ai/hastighed.
