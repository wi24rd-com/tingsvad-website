Case file 29 · The thing's machine park

Eighteen machines at the ford.

The thing’s machine park stands at the ford: each machine has a room of its own. If you want to see how they are built, it is all in the machine room. The machines are configured to decide nothing. That was not difficult.

The characters are fiction. What the machine says is fiction. What the thing decides is nothing. Anything that does not come from the machine is marked as an editorial example.

Case file 10 · Convening

Convene the thing

Pick a date. The network checks whether those present can attend. They cannot. But the reasons differ.

Ragnhild can always attend. She has been able to since the year 1000. That is not the problem.

Case file 29 · Exhibit · The cow, as seen by a machine

Exhibit: The cow, as seen by a machine

In 2012 the thing sent a picture of the cow to a neural network that had just learned to recognise cats. The reply has been preserved and now hangs here in the machine park, since the network was the thing’s first machine and nobody knew where else to put it. The network drew a box around the cow and wrote KAT 62 %. The remaining 38% are unspecified. The thing has asked for clarification. The network replied with the same box.

Ulf Blackcloak has since argued that his witness is therefore a cat, and that cats cannot testify. The question of whether the cow is a cat has been raised as a separate case. It is adjourned.

There is more between the stones.

The thing has more to rummage in. None of it decides the case.
