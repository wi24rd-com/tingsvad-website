One stool for the whole internet. Move it together with everyone else.

Case file 26 · The shared stool

The stool has been granted. It is just in the wrong place.

Toke’s stool has been granted but not used, because the case on sitting down is adjourned. Meanwhile it can be moved. There is only one stool, and everyone here right now moves the same one: the server owns the position, and every move is sent to everyone. The stool can cross the river on the stepping stones. The fourth one wobbles.

There is more between the stones.

The thing has more to rummage in. None of it decides the case.
