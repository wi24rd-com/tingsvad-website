The speed

How fast the thing answers, measured by the guests themselves.

Lighthouse measures the pages in a laboratory. Here they are measured with real guests: how long until the largest content was on screen, how fast the page answered a click, and whether it jumped around on the way. Cloudflare Web Analytics measures it with a small script without cookies and without knowing the guest, and the thing fetches the figures every hour.

How it is counted

  1. Web Analytics beacon
  2. GraphQL Analytics API
  3. Cron Trigger
  4. Workers KV
  5. Workers Cache
  6. Your browser

The source

Cloudflare Web Analytics (Real User Monitoring) for tingsvad.dk, fetched from the GraphQL Analytics API at account level. The token may only read analytics.

Every hour

A Cron Trigger in the thing’s Worker fetches the last 7 days: page views, Core Web Vitals, load times and where the time goes. Each part is fetched separately, so one failure does not take the rest with it.

The limits

Good, needs improvement and poor follow Google’s limits: LCP 2.5 and 4 seconds, INP 200 and 500 milliseconds, CLS 0.1 and 0.25. The figures are the 75th percentile, as Google uses.

What is not measured

Guests who block the script or have no JavaScript are not counted. No IP addresses, cookies or fingerprints are stored.

Raw figures as JSON: /api/ting-ai/hastighed.
