Case file 31 · The emergency drills

When something goes wrong

Each drill runs the real code – the timeout wrapper around the language model, the raven exchange’s queue consumer and the voting logic – against fake services in the Worker’s memory. Nothing in production is affected, and no button here can make a real endpoint fail. Everything is labelled as a simulation.
